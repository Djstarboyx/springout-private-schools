SPRINGOUT PRIVATE SCHOOLS — WEBSITE REDESIGN

PREVIEW LOCALLY
1. Extract this folder to your computer.
2. Keep index.html, styles.css, script.js and the images folder together.
3. Double-click index.html to preview the website in your browser.

FILES
- index.html: website structure and page content
- styles.css: responsive layout, colour palette, hover effects and animations
- script.js: mobile navigation, scroll reveal and sticky-header behaviour
- images/: original school badge and photographs supplied with the project

CUSTOMISE
- Update wording in index.html.
- Replace the files in images/ with approved school photos, keeping the same filenames, or update the image paths in index.html.
- Change colours near the top of styles.css in the :root section.
- Update phone numbers, address and school hours in the contact section if any details change.

NOTES
- This is a static HTML/CSS/JavaScript website. No build step or package installation is required.
- The WhatsApp link uses the first phone number already supplied in the original website files.
- The design uses subtle entrance and hover animations, and respects reduced-motion preferences.
- The school programme copy is introductory and should be reviewed by the school before publishing.
